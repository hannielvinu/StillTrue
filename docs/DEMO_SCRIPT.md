# Three-minute demo

0:00–0:25 — “An AI answer can sound confident after a rule has changed.” Introduce the tax-form example as a reported user case, not a captured model answer unless an actual capture file exists. Avoid unsupported historical specifics.

0:25–0:45 — Paste an answer. Explain the default PII masking. Choose a jurisdiction/topic pack and show its approved official domains.

0:45–1:45 — Run the live pipeline only with configured credentials. Show extracted claims, source dates, copied evidence and Still true/Changed/Unconfirmed labels. Explain why Unconfirmed is useful. If using mock mode, say “This is a synthetic offline demonstration” while keeping its banner visible.

1:45–2:15 — Open a source, show model agreement and heuristic score. Explain Bifrost routes model calls; Tavily retrieves source material. Show the API route.

2:15–2:40 — Show the recorded run only if a real capture and real verification exist. Otherwise state recording is not available. Benchmark: show measured report only when one exists; otherwise “Not yet run.”

2:40–3:00 — Limits and next steps: source coverage, model errors, human benchmark labels, verify before acting.

Never present staged/illustrative text as a real captured answer. Never improvise benchmark numbers. A legal example such as Moffatt v. Air Canada should be used only after checking the primary decision; this build does not assert an independently retrieved case citation or damages amount.
