# Deck generator

`npm install pptxgenjs@3.12.0`, then from this folder: `node stilltrue.js ../StillTrue_Pitch.pptx` and
`soffice --headless --convert-to pdf ../StillTrue_Pitch.pptx`. Fonts: Poppins (headings) and Inter (body).
Every number on the slides comes from `benchmark/results/20261121T122711.json`.
